# Propsでさまざまなデータ型を渡す

ここまでで、propsを使ってコンポーネントにデータを渡す方法を学びました。

今までは主に下のような「文字列（string）」を渡していました。

```jsx
<Recipe name="カレーライス" />
```

---

## でもReactではもっとできる

HTMLでは、基本的にすべての値は「文字列」として扱われます。

```html
<input type="text" />
```

=> `"text"` は文字列

---

しかし、ReactはJavaScriptなので
=> **文字列以外のデータも渡すことができます**

---

## Food Journalで考えてみよう

今のアプリのデータ

```js
{
  id: 1,
  name: "カレーライス",
  img: curryrice,
  ingredients: "...",
  description: "..."
}
```

---

## ① 数値（number）を渡す

例えば「人気度」を追加するとします。

```jsx
<Recipe popularity={5} />
```

=> `{}` を使うと「数値」として渡せる

---

## ② 真偽値（boolean）を渡す

例えば「おすすめかどうか」

```jsx
<Recipe isRecommended={true} />
```

=> true / false をそのまま渡せる

---

## 使い方

```jsx
{props.isRecommended && <p>おすすめ！</p>}
```

=> true のときだけ表示

---

## ③ 配列（array）を渡す

材料を配列で持つこともできます

```jsx
<Recipe 
  ingredients={["玉ねぎ", "にんじん", "じゃがいも"]}
/>
```

---

## ④ オブジェクトもOK

```jsx
<Recipe 
  info={{ time: "30分", level: "簡単" }}
/>
```

---

## 復習：なぜ {} が必要？

```jsx
<Recipe popularity={5} />
```

=> `{}` = JavaScriptモード

### これだとエラー

```jsx
<Recipe isRecommended=true />
```

=> JSXでは `{}` が必要

---

## まとめ

* Reactでは文字列以外も渡せる
* 数値・boolean・配列・オブジェクトOK
* JavaScriptの値は `{}` で囲む

### 応用イメージ

```jsx
<Recipe
  name="カレーライス"
  popularity={5}
  isRecommended={true}
  ingredients={["玉ねぎ", "にんじん"]}
/>
```
