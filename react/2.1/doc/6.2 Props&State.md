# propsとstateの違い

## propsとは？

propsとは**コンポーネントに外から渡されるデータ**

#### 例

```jsx
<Recipe name="カレーライス" />
```

=> `name` が props

### 役割

* コンポーネントを動かすための情報
* コンポーネントの表示を決める
* 設定（config）のようなもの

### ポイント

=> **propsは変更できない（immutable）**


#### なぜ変更できないの？

関数で考えてみましょう

```js
function add(a, b) {
  return a + b;
}

add(1, 2) // → 3
```

もし中でこうしたら

```js
function add(a, b) {
  a = 42;
  return a + b;
}
```

=> 結果がめちゃくちゃになる（予想できない）

=> だから**引数（= props）は変えてはいけない**

### Reactでも同じ

```jsx
function Navbar(props) {
  props.logo = "other.png"; //NG
}
```

=> 外から渡された値を勝手に変えるのはダメ

---

## stateとは？

stateとは**コンポーネントの中で管理されるデータ**

#### 例

```jsx
let count = 0;
```

に似ているけど違う

=> **stateはReact専用の特別なデータ**

### いつ使う？

=> **値が変わるとき**

* ボタンをクリック
* 入力フォーム
* 表示の切り替え

### 重要ポイント

=> stateは変更できる

=> 変更すると画面も変わる

---

## render（レンダー）とは？

=> コンポーネント関数が実行されること

```jsx
function App() {
  return <h1>Hello</h1>;
}
```

=> Reactはこの関数を実行して画面を作る

### 再レンダーされるタイミング

Reactは次のときに再実行されます

#### ① propsが変わったとき

```jsx
<Recipe name="カレー" />
↓
<Recipe name="寿司" />
```

#### ② stateが変わったとき

=> これが一番重要

### ポイント

=> 普通の変数は変えても画面は変わらない

=> **stateを変えると画面が更新される**

---

## Reactの考え方

=> **画面 = stateによって決まる**

### イメージ

スイッチと電気

* state = スイッチ
* UI = 電気の状態

```text
OFF → 暗い
ON  → 明るい
```

=> stateが変わると自動で表示が変わる

---

## Reactのすごいところ

=> 自分でDOM操作しなくていい

=> stateを変えるだけでOK

---

## まとめ

### props

* 外から渡される
* 変更できない

### state

* コンポーネント内で管理
* 変更できる
* 変更するとUIが更新される
