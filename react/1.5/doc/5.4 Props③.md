# Propsを受け取る

前のレッスンでは、propsを使ってコンポーネントにデータを渡す方法を学びました。

=> HTMLの `src` や `href` のようにReactでもコンポーネントに情報を渡せる

---

## Food Journalアプリでの状況

今、あなたのアプリにはこのようなデータがあります

```js
const recipes = [
  {
    id: 1,
    name: "カレーライス",
    img: curryrice,
    ingredients: "...",
    description: "..."
  },
  ...
];
```

そして `App.js` では、`Recipe` コンポーネントにデータを渡しています。

```jsx
<Recipe 
  name={recipes[1].name}
  img={recipes[1].img}
  ingredients={recipes[1].ingredients}
  description={recipes[1].description}
/>
```

---

## では、Recipe側ではどうする？

ここが今回のポイントです。

Reactのコンポーネントは、関数と同じように
**引数としてデータを受け取ることができます。**

---

## 例（Recipe.js）

```jsx
export default function Recipe(props) {
  console.log(props);

  return (
    <div>
      <h2>カレーライス</h2>
    </div>
  );
}
```

### console.logすると何が見える？

=> propsは「オブジェクト」になっています

```js
{
  name: "カレーライス",
  img: "...",
  ingredients: "..."
}
```

### なぜオブジェクト？

`App.js` で渡したデータがそのまままとめられているからです。

=> props = データの箱

### ポイント

```jsx
<Recipe name="カレーライス" />
```

↓

```js
props = {
  name: "カレーライス"
}
```

---

## よくあるミス

```jsx
<h2>props.name</h2>
```

=> NG -> そのまま文字として表示される

### 正しい書き方

```jsx
<h2>{props.name}</h2>
```

=> `{}` をつけるとJavaScriptとして評価される

---

## イメージ

```jsx
export default function Recipe(props) {
  return (
    <div>
      <h2>{props.name}</h2>
      <img src={props.img} />
      <p>{props.ingredients}</p>
      <p>{props.description}</p>
    </div>
  );
}
```
---

## ポイント

propsの名前は一致していないと動きません

NG

```jsx
<Recipe image={curryrice} />
```

```jsx
<img src={props.img} />
```

=> 表示されない

OK

```jsx
<Recipe img={curryrice} />
```

```jsx
<img src={props.img} />
```

---

## まとめ

* propsはコンポーネントに渡されるデータ
* propsはオブジェクトとして受け取る
* `props.name` のようにアクセスする
* JSXでは `{}` を使う
* 名前は必ず一致させる
