# Reactコンポーネントの基本 ①

## なぜReactが便利なのか? -> コンポーネント

Reactの大きな特徴の一つは **「コンポーネント化（Composable）」** です。

UIを小さな部品に分けて、それらを組み合わせてアプリを作ることができます。

例えば、ナビゲーションバーのようなUIは通常とても長いコードになります。
もしHTMLだけで書くと、各ページごとに同じコードをコピー＆ペーストする必要があります。

しかしReactでは、そのようなUIを**1つのコンポーネントとして定義**することで、
何度でも再利用することができます。

---

## Navbarコンポーネント

今回の例では、ナビゲーションバーをコンポーネントとして作成しています。 (中身の詳細は[index.js](../src/index.js)でみえます)

```jsx
function Navbar() {
  return (
    <nav className="navbar navbar-expand-lg navbar-dark bg-dark">
      ...
    </nav>
  );
}
```

### ポイント

* `function Navbar()` → コンポーネントを定義、関数を作るだけでコンポーネントになる
* `return (...)` → JSX（HTMLのような構文）を返す
* JSXでは**必ず1つの親要素で全体をラップする必要がある**（例：`<div>` や `<>...</>`）
* 従来のHTMLの`class`ではなく、 **`className`** を使う（Reactのルール）
* コンポーネントは**パスカルケース（PascalCase）**で命名する（例：Navbar, Body, WhateverNameYouWant）

---

## コンポーネントの使い方（レンダリング）

作成したコンポーネントは、HTMLタグのように使えます。

```jsx
root.render(
  <div>
    <Navbar />
  </div>
);
```

### ポイント

* `<Navbar />` → Navbarコンポーネントを表示
* 自分で作ったコンポーネントをタグのように使える
* `<Component />` のように**自己終了タグ(Self Closing Tag)**で書く

---

## 重要な考え方

Reactでは：

* UIを「部品（コンポーネント）」として作る
* それらを組み合わせて画面を作る

=> これがReactのコア思想です

---

## まとめ

* コンポーネントは「再利用できるUIパーツ」
* 関数で簡単に作れる
* JSXで見た目を書く
* `<Component />`の形で使う
