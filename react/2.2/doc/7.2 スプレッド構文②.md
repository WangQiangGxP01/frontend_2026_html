# スプレッド構文（...）のいろいろな使い方

```js
//配列に要素を追加する
[...prevFavThing, "Test"]
```

これまで学びました

ここでは、**他のよく使うパターン**をまとめて紹介します。

---

### ① 配列のコピー

```js id="a1v9xk"
const arr = ["🍎", "🍌"]

const newArr = [...arr]

//結果
["🍎", "🍌"]
```

=> 元の配列は変わらない

### ② 配列の結合

```js id="b7p3hm"
const arr1 = ["🍎"]
const arr2 = ["🍌"]

const merged = [...arr1, ...arr2]

//結果
["🍎", "🍌"]
```


### ③ 先頭に追加

```js id="d8o7lz"
const arr = ["🍎", "🍌"]

const newArr = ["🍇", ...arr]

//結果
["🍇", "🍎", "🍌"]
```

### ④ 配列の一部だけ変更

```js id="m9q2sr"
const arr = ["🍎", "🍌", "🍊"]

const newArr = arr.map((item) =>
  item === "🍌" ? "🍇" : item
)

//結果
["🍎", "🍇", "🍊"]
```

=> 新しい要素を追加

---

### ⑤ オブジェクトのコピー

```js id="6aztql"
const recipe = {
  name: "カレー",
  time: "30分"
}

const newRecipe = { ...recipe }
```

=> 同じ内容の新しいオブジェクト

### ⑥ オブジェクトにプロパティ追加

```js id="s5k2wn"
const recipe = {
  name: "カレー"
}

const newRecipe = {
  ...recipe,
  time: "30分"
}

//結果
{
  name: "カレー",
  time: "30分"
}
```

### ⑦ 値の上書き

```js id="b8n3ux"
const recipe = {
  name: "カレー",
  time: "30分"
}

const newRecipe = {
  ...recipe,
  time: "45分"
}
```

=> `time` が上書きされる

### ⑧ propsにまとめて渡す（React）

```jsx id="2e9zwd"
<Recipe {...recipe} />

//これは下と同じ
<Recipe
  name={recipe.name}
  time={recipe.time}
/>
```

---

### ⑨ 配列 + state

```js id="b0p7mf"
setItems(prev => [...prev, newItem])
```

=> Reactで一番よく使う形

### ⑩ オブジェクト + state

```js id="v1a6qx"
setUser(prev => ({
  ...prev,
  name: "太郎"
}))
```

=> 一部だけ更新

---

## まとめ

| パターン                 | 使い方       |
| -------------------- | --------- |
| [...arr]             | コピー       |
| [...arr, item]       | 追加        |
| [item, ...arr]       | 先頭追加      |
| [...arr1, ...arr2]   | 結合        |
| {...obj}             | オブジェクトコピー |
| {...obj, key: value} | 追加・更新     |
