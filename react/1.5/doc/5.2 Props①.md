# Props（プロップス）とは？

まずは、Reactの **props（プロップス）** の考え方を理解するために、
身近な例から見ていきましょう。

---

## HTMLの例

HTMLのタグには「情報を渡す仕組み」があります。

```html
 <!-- #1 -->
<a href="https://google.com">Google</a>
 <!-- #2 -->
<img src="image.png" />
 <!-- #3 -->
 <input placeholder="名前" type="text" />
```

=> #1 `href` がないとリンクは動きません

=> #2 `src` がないと画像は表示されません

=> #3 `type` や `placeholder` を変えると見た目や機能が変わる

---

## JavaScriptの例

```js
function add() {
  return 1 + 2;
}
```

=> いつも「3」しか返せない（使い回せない）

```js
function add(a, b) {
  return a + b;
}
```

=> どんな数字でも計算できる（再利用できる）

---

## 共通しているポイント

=> **外から情報を渡すことで、より便利になる**

---

## Food Journalアプリで考える

今のあなたのアプリには、こういうデータがあります([data.js](../src/data.js)に保存してる)

```js
const recipes = [
  {
    id: 1,
    name: "カレーライス",
    img: curryrice,
    ingredients: "...",
    description: "..."
  },
  ...
];
```

### 今の問題

もし `Recipe` コンポーネントの中に

```jsx
<h2>カレーライス</h2>
```

のように直接書いてしまうと…

=> **どのカードも全部カレーになる**

### なぜダメ？

これは、さっきのJavaScriptと同じです。

```js
function add() {
  return 1 + 2;
}
```

=> 固定されているから使い回せない

---

## 解決方法（props）

Reactでは、HTMLと同じように
コンポーネントに「情報」を渡すことができます。

これが **props** です。


### イメージ

HTML

```html
<img src="image.png" />
```

React

```jsx
<Recipe name="カレーライス" />

<Recipe blahblahblah="カレーライス" />
```

※ propsの名前は自分で自由に決められますが、あとで見ても分かるように分かりやすい名前にしましょう。

---

## Food Journalでの使い方

```jsx
<Recipe
  name="カレーライス"
  img={curryrice}
  ingredients="玉ねぎ..."
/>
```

=> コンポーネントにデータを渡している

---

## なぜこれが重要？

propsを使うと

* 同じコンポーネントを使い回せる
* データだけ変えればOK
* コードがスッキリする

---

## まとめ

* props = コンポーネントに渡すデータ
* HTMLの属性（href / src）と同じ考え方
* JavaScriptの引数（a, b）と同じ考え方
* Food Journalでは「料理データ」を渡す
