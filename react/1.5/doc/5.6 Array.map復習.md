# map関数の復習

このレッスンでは、これからReactで使う重要な考え方に入る前に、
**JavaScriptの `map()` 関数**を復習します。

---

## なぜmapを学ぶの？

これからReactでは下のようなことをします

=> **データ（配列） → 画面に表示するUIに変換する**

そのときに使うのが `map()` です。

---

## mapとは？

`map()` は配列に対して使う関数で、

=> 配列の中の1つ1つのデータを処理して
=> 新しい配列を作る

という働きをします。

---

## 基本の例

```js id="b5r6lz"
const nums = [1, 2, 3, 4, 5];

const squares = nums.map(function(num) {
  return num * num;
});

console.log(squares);
```

---

### 出力

```js id="j3t0z4"
[1, 4, 9, 16, 25]
```

---

## 仕組み

* `map()` は配列の1つ1つの要素を取り出す
* その要素に対して処理を行う
* `return` した結果が新しい配列になる

=> 元の配列と同じ長さの新しい配列ができる

---

## 例②：文字の加工

```js id="7zj3v8"
const names = ["taro", "hanako", "jiro"];

const capitalized = names.map(name => {
  return name[0].toUpperCase() + name.slice(1);
});
```

---

### 出力

```js id="rj5z6s"
["Taro", "Hanako", "Jiro"]
```

---

## 例③：HTMLっぽい形にする

```js id="wzv9q2"
const foods = ["カレー", "寿司", "ラーメン"];

const list = foods.map(food => {
  return `<p>${food}</p>`;
});
```

---

### 出力

```js id="f3k1px"
[
  "<p>カレー</p>",
  "<p>寿司</p>",
  "<p>ラーメン</p>"
]
```

=> まだただの文字列ですが、ReactではこれがUIになります

---

## Reactとの関係

これからやること

```js id="9v6lpa"
const recipes = [
  { name: "カレー" },
  { name: "寿司" },
  { name: "ラーメン" }
];
```

```jsx id="g0m8ks"
recipes.map(recipe => {
  return <Recipe name={recipe.name} />;
});
```

=> **データ → コンポーネント**

---

## まとめ

* `map()` は配列を変換するための関数
* 各要素に対して処理を行う
* 新しい配列を返す
* ReactではUIを作るために使う
