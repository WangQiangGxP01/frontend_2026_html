# 三項演算子（ternary）とstateの正しい使い方

## 今の問題点

```jsx
setIsHappy("no");
```

=> 毎回同じ値になる

=> これ以上変化しない

このレッスンを一気に理解して問題を解決しましょう

---

## 三項演算子（ternary）とは？

三項演算子は**if / else を1行で書く方法**

```js
条件 ? trueのとき : falseのとき
```

#### 例

```js
const isHappy = true;

const answer = isHappy ? "はい" : "いいえ";
```

### JSXの中で使う

Reactでは`{JavaScript}`が使えるので、

```jsx
<button>
  {isHappy ? "はい" : "いいえ"}
</button>
```

=> 直接書ける！

=> ボタンの表示が状態によって変わる


---

## useStateでstateを作る

```jsx
import React from "react";

const [isHappy, setIsHappy] = React.useState(true);

//stateを変更する
function handleClick() {
  setIsHappy(false);
}
```

=> これで

* stateが変わる
* Reactが再レンダーする
* 画面が更新される

---

## でもまだ不十分

* `false`に変更すると、`true`に戻らない

そこで↓

```jsx
setIsHappy(!isHappy);
```

=> 動くけど、**安全ではない場合がある**

---

## callback関数を使う

```jsx
function handleClick() {
  setIsHappy(prev => !prev);
}
```

---

## 何が起きている？

* `prev` → 前のstate
* `!prev` → 反対の値

=> **前の状態を元に新しい状態を決めている**

---

## なぜこれが必要？

Reactは**state更新をまとめて処理する（バッチ処理）**

#### 問題のある例

```jsx
setCount(count + 1);
setCount(count + 1);
setCount(count + 1);
```

=> 期待：+3
=> 実際：+1になることがある

### 正しい書き方

```jsx
setCount(prev => prev + 1);
setCount(prev => prev + 1);
setCount(prev => prev + 1);
```

=> 結果：+3（正しく動く）

---

```

```
