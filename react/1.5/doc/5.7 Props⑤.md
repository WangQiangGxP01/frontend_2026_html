# Food Journalアプリ：データからUIを作る（mapの実践）

これまで学んできた内容を使って、いよいよ
**データからコンポーネントを自動生成する**
ステップに入ります。

---

## 事前準備

これまでのように、コンポーネントの中に直接データを書くのではなく、
 `data.js` に料理データをまとめています。

```js
const recipes = [
  {
    id: 1,
    name: "カレーライス",
    img: curryrice,
    ingredients: "...",
    description: "..."
  },
  ...
];
```

=> 1つのオブジェクト = 1つの料理

---

## やること

今回のチャレンジは

* `data.js` を読み込む
* `map()` を使う
* データごとに `Recipe` コンポーネントを作る
* 画面に表示する

---

### ① データをimport

```jsx
import recipes from "./data";
```

### ② mapでコンポーネントを作る

```jsx
const recipeElements = recipes.map((recipe) => {
  return (
    <Recipe
      name={recipe.name}
      img={recipe.img}
      ingredients={recipe.ingredients}
      description={recipe.description}
    />
  );
});
```

#### ここで何が起きている？

=> 配列の1つ1つのデータを使って

=> `<Recipe />` を作っている

### ③ 表示する

```jsx
return (
  <div>
    {recipeElements}
  </div>
);
```

=> `{}` の中でJavaScriptを実行

---

## 結果

今までは

```jsx
<Recipe />
<Recipe />
<Recipe />
```

=> 手で書いていた

これからは

```jsx
recipes.map(...)
```

=> **自動で増える**

---

## なぜこれが重要？

* データが増えてもコードは変えなくていい
* 再利用できる
* Reactらしい書き方になる

---

## 少し発展（オブジェクトそのまま渡す）

```jsx
<Recipe {...recipe} />
```

=> 全部のデータを一気に渡せる

---

## イメージ

```text
データ（配列）
↓
map()
↓
コンポーネント（Recipe）
↓
画面表示
```

---

## 学習ポイント

* `map()` は配列を回す
* JSXをreturnできる
* propsでデータを渡す
* `{}` で表示する

## まとめ

* データを使ってUIを作る
* `map()` で繰り返し処理
* コンポーネントを再利用
* 手書きから卒業！
