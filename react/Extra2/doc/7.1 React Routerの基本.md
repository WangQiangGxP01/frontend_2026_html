# React Routerの基本

Reactは基本的に1つのHTMLの中で画面を作ります。

でも実際のWebサイトでは

```txt
/
/about
/products
```

のように、URLごとに別の画面を見せたいです。

---

## React Routerとは？

React Routerは

**URLとコンポーネントをつなげるためのライブラリ**

です。

例えば

```jsx
{
  path: "/products",
  element: <Products />
}
```

=> `/products` にアクセスしたとき

=> `<Products />` を表示する

という意味です。

---

## Link

普通のHTMLでは

```html
<a href="/products">Products</a>
```

を使います。

でもReact Routerでは

```jsx
<Link to="/products">教材一覧</Link>
```

を使います。

### なぜ？

`Link`を使うと、ページ全体を再読み込みせずに画面を切り替えられます。

=> Reactアプリの中だけで移動できる

---

## NavLink

`NavLink`は、今開いているページに`active`クラスを付けられます。

```jsx
<NavLink to="/lessons">レッスン</NavLink>
```

=> 現在のURLが`/lessons`ならactiveになる

---

## まとめ

- React RouterはURLとコンポーネントをつなげる
- `Link`はページ再読み込みなしで移動する
- `NavLink`は今いるページを見せやすい
- ルートの設定は`src/router.jsx`を見る
