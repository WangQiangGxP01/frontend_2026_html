# スプレッド構文（...）復習

```js
setMyFavoriteThing(prevFavThing => [
  ...prevFavThing,
  "Test"
])
```

今回のコードを、**別の例**で考えてみましょう。

---

## 例：好きな食べ物リスト

```js
//今のstate
prevFood = ["寿司", "ラーメン"]

// スプレッドする
...prevFood

//こうなる
"寿司", "ラーメン"
```

---

## 新しい配列を作る

```js
[
  ...prevFood,
  "カレー"
]

//結果
["寿司", "ラーメン", "カレー"]
```

### つまり

=> 「今までの食べ物を全部コピーして」
=> 「新しい食べ物を1つ追加している」

---

## React的な正しい考え方

```js
setFood(prevFood => [
  ...prevFood,
  "カレー"
])
```

=> 新しい配列を作る

### NG例

```js
prevFood.push("カレー")
```

=> 元の配列(state)を変えるのはダメ

```js
prevFood[0] = "うどん"
```

=> 直接変更もダメ

---

# まとめ

```text
前のデータ
["寿司", "ラーメン"]

↓

コピー（...）
"寿司", "ラーメン"

↓

新しく作る
["寿司", "ラーメン", "カレー"]
```

* スプレッドは「コピー＋追加」に使う
* 元のデータは絶対に変えない
