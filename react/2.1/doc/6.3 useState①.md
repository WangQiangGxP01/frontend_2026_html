# useStateの基本

これまで学んだ内容の中で、1つ重要な問題がありました。

---

## 普通の変数ではダメ

例えば

```jsx
let state = "yes";

function handleClick() {
  state = "no";
}

return <h1>{state}</h1>;
```

=> 画面で表示はされる

=> でもボタンを押して変更しようとしても**画面は更新されない**

### なぜ？

=> Reactは「ただの変数の変更」を検知できない


### ポイント

=> **変数を変えても再レンダーされない** = **画面が更新されない**

---

## 解決方法：useState

### 使い方

```jsx
import React from "react";

const result = React.useState("yes");

//console.log()で見える
["yes", function]
```

=> 配列が返ってくる

#### 中身

* 1つ目 → 現在の値（state）
* 2つ目 → 更新する関数

### 初期値

```jsx
React.useState("yes");
```

= `"yes"` が最初の状態になる

### 画面で表示する

```jsx
const result = React.useState("yes");

return <h1>{result[0]}</h1>;
```

=> stateを表示

---

## まとめ

* 普通の変数はReactでは使えない（更新されない）
* stateを使う必要がある
* `useState()` でstateを作る
* 初期値を設定できる
