# Reactコンポーネントの基本 ④

## 親子コンポーネント

### 親子コンポーネントとは？

Reactでは、コンポーネントの中に別のコンポーネントを入れることができます。

=> これを「親子関係」と呼びます  

### 例：

```jsx
function Header() {
  return <h1>My Website</h1>;
}

function Main() {
  return <p>Welcome to my page!</p>;
}

function Footer() {
  return <small>© 2026 My Website</small>;
}
````

次に、それらをまとめる「Page」コンポーネントを作ります。

```jsx id="4v7z9c"
function Page() {
  return (
    <div>
      <Header />
      <Main />
      <Footer />
    </div>
  );
}
```

最後に、`App` から `Page` を呼び出します。

```jsx id="g8k2lm"
export default function App() {
  return <Page />;
}
```

---

## イメージ

* App → Page を表示
* Page → Header / Main / Footer をまとめる

=> 小さい部品を組み合わせて1つの画面を作るのがReactの考え方
