# JSXの `{}` とは？

Reactでは、HTMLのように見えるコード（JSX）の中で  
**JavaScriptを書くときに `{}` を使います**

=> 簡単にいうと `{}` は　**「JavaScriptの世界」**　に入る入口です

---

## 例1：JavaScriptの値を表示する

```jsx
import myPic from "./images/react.png";

export default function App() {
  const name = "Peter";
  
  return (
    <div>
      <img src={myPic} />
      <h1>Hello {name}!</h1>
    </div>
  );
}
```

=>  `{}` の中に変数を書くことで、JavaScriptの値を使える

---

## 例2：関数を使う

```jsx
function getGreeting() {
  return "Good morning!";
}

export default function App() {
  return <h1>{getGreeting()}</h1>;
}
```

=> `{}` の中で関数も実行できる

---

## 例3：インラインCSS（ `{{}}` ）

Reactでは、CSSを直接書くこともできます。

```jsx
export default function App() {
  return (
    <h1 style={{ color: "red", fontSize: "20px" }}>
      Hello React
    </h1>
  );
}
```

- CSSは**オブジェクト形式**で書く（`color: "red"` など）
- プロパティは **camelCase**（`background-color` → `backgroundColor`）

### なぜ `{}` が2つ？

```jsx
style={{ color: "red" }}
```

* 外側の `{}` → 「JavaScriptの世界」に入る、JavaScriptを書く場所
* 内側の `{}` → オブジェクト（CSSの値）

=> **JSXの中にオブジェクトを書くので2重になる**

---

## まとめ

### `{}` の役割

* JavaScriptを書く場所
* 変数・関数・値を使える

### `{{}}` の意味

* 外：JSXの中のJavaScript
* 内：オブジェクト（CSS）
