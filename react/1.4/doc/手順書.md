# まとめ練習：My Favorite Foods App を最初から作ってみよう

このパートの内容を使って、画像のような **「My Favorite Food App」** を最初から作ってみましょう。

この練習では、以下を復習できます。

- コンポーネントを分ける
- `import / export` を使う
- JSXを書く
- `ul` / `li` を使う
- CSSで見た目を整える
- 画像を読み込む

---

## 完成イメージ

[イメージ図](../public/example.png)

作るアプリの内容：

- 上にナビゲーションバーがある
- Reactロゴとタイトルを表示する
- メイン部分に「好きな食べ物」という見出しを表示する
- その下に好きな食べ物を3つ、リストで表示する


---

## フォルダ構成

```bash
src
├── components
│   ├── Navbar.jsx
│   └── MainContent.jsx
├── images
│   └── react-logo.png
├── App.jsx
├── index.jsx
└── style.css
```
---

## `style.css` 

`src/style.css` に以下を参考にします。

- アプリ背景色：#333333
- 文字色：#FFFFFF
- ナビゲーションバー背景色：#21222a
- ナビゲーションバー文字色：#FFFFFF
- ロゴサイズ（高さ・太さ）：50px
- タイトル「好きな食べ物」の色：#61dafb
- リストスタイル：●（塗りつぶし）
- リストマーカー色：#61dafb

上記の指定に加えて、必要なCSSを自分で考えながら、完成イメージ（画像）に近づけてみましょう。
