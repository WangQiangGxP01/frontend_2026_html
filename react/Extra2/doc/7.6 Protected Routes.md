# Protected Routes

Protected Routesは

**ログインしていない人には見せないページ**

です。

---

## このアプリの例

先生用ページ:

```txt
/dashboard
```

このページはログインしていないと見られません。

---

## requireAuth

`src/router.jsx`にこの関数があります。

```jsx
function requireAuth({ request }) {
  const user = getUser();
  if (!user) {
    const url = new URL(request.url);
    throw redirect(`/login?redirectTo=${url.pathname}`);
  }
  return user;
}
```

やっていること:

1. ログイン済みか確認する
2. ログインしていなければ`/login`へ移動する
3. 元のURLを`redirectTo`に入れる
4. ログイン済みならユーザー名を返す

---

## loaderで守る

```jsx
{
  path: "dashboard",
  element: <Dashboard />,
  loader: requireAuth
}
```

=> `/dashboard`を表示する前に`requireAuth`が動く

=> 未ログインなら画面を表示しない

---

## redirectTo

未ログインで`/dashboard/notes`を開くと

```txt
/login?redirectTo=/dashboard/notes
```

のようになります。

ログイン後にこのURLへ戻すためです。

---

## 注意

この教材では練習用に`localStorage`を使っています。

本番アプリでは、ログイン状態はサーバーや認証サービスと一緒に確認します。

---

## まとめ

- Protected Routeはログイン必須のページ
- `loader`で表示前にチェックできる
- 未ログインなら`redirect()`する
- `redirectTo`でログイン後に元のページへ戻せる
- 練習用と本番用の認証は違う
