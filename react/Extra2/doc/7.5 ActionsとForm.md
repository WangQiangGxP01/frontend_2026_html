# ActionsとForm

React Routerでは、フォーム送信もルートで扱えます。

送信を受け取る関数が`action`です。

---

## Form

React Routerのフォームは

```jsx
<Form method="post">
  <input name="username" />
  <button>ログインする</button>
</Form>
```

のように書きます。

普通の`form`ではなく

```jsx
import { Form } from "react-router-dom";
```

で読み込む`Form`です。

---

## action

ルートに`action`を書きます。

```jsx
{
  path: "login",
  element: <Login />,
  action: async ({ request }) => {
    const formData = await request.formData();
    const username = formData.get("username");
  }
}
```

=> フォーム送信を受け取る

=> 入力値を読む

=> 保存やチェックをする

---

## エラーを返す

入力が足りないとき

```jsx
return { error: "名前は2文字以上で入力してください。" };
```

のように返します。

画面では

```jsx
const actionData = useActionData();
```

で受け取ります。

---

## 送信中のUI

```jsx
const navigation = useNavigation();
const isSubmitting = navigation.state === "submitting";
```

これで送信中かどうか分かります。

```jsx
{isSubmitting ? "ログイン中..." : "ログインする"}
```

=> ボタンの表示を変えられる

---

## redirect

ログイン成功後は

```jsx
return redirect("/dashboard");
```

で移動できます。

---

## まとめ

- `<Form method="post">`は`action`に送信される
- `request.formData()`で入力値を読む
- `useActionData()`でactionの戻り値を受け取る
- `useNavigation()`で送信中の状態を見られる
- `redirect()`で送信後に移動できる
