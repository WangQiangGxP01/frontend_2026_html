# LoadersとErrors

React Routerでは、画面を表示する前にデータを準備できます。

それが`loader`です。

---

## loader

```jsx
{
  path: "products/:productId",
  element: <ProductDetail />,
  loader: ({ params }) => {
    const product = getProduct(params.productId);
    return product;
  }
}
```

=> URLから`productId`を取る

=> そのIDの商品を探す

=> コンポーネントへ渡す

---

## useLoaderData

コンポーネント側では

```jsx
const product = useLoaderData();
```

でloaderの戻り値を受け取ります。

つまり

```jsx
loader return product
```

したものを

```jsx
useLoaderData()
```

で使います。

---

## URL Params

```txt
/products/router-map
```

ルート設定が

```jsx
path: "products/:productId"
```

なら

```jsx
params.productId
```

は

```txt
router-map
```

になります。

---

## Error

商品が見つからないときは

```jsx
throw new Response("Product not found", { status: 404 });
```

のようにエラーを投げます。

そうすると`errorElement`が表示されます。

---

## まとめ

- `loader`は表示前にデータを準備する
- `useLoaderData()`でデータを受け取る
- `params`でURLの動的な値を読める
- 見つからないデータは404エラーにする
- `errorElement`でエラー画面を出す
