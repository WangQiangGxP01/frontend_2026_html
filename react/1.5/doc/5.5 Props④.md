# Propsの分割代入（Destructuring）とは？

ここまでで、propsは「オブジェクト」として受け取ることを学びました。

```jsx
function Recipe(props) {
  return <h2>{props.name}</h2>;
}
```

---

## オブジェクトの復習

JavaScriptでは、オブジェクトから値を取り出す方法が2つあります。

### ① 通常の書き方

```js
const person = {
  name: "カレーライス",
  ingredients: "玉ねぎ..."
};

console.log(person.name);
```

### ② 分割代入（Destructuring）

```js
const { name, ingredients } = person;

console.log(name);
```

=> `person.name` と書かなくてもよくなる

---

## Reactでの使い方

propsもオブジェクトなので、同じことができます。

### 通常の書き方

```jsx
function Recipe(props) {
  return (
    <div>
      <h2>{props.name}</h2>
      <p>{props.ingredients}</p>
    </div>
  );
}
```

### 分割代入を使う

```jsx
function Recipe({ name, ingredients }) {
  return (
    <div>
      <h2>{name}</h2>
      <p>{ingredients}</p>
    </div>
  );
}
```

=> `props.` を書かなくてよくなるのでスッキリ！

---

## Food Journalアプリでの例

```jsx
function Recipe({ name, img, ingredients, description }) {
  return (
    <div>
      <h2>{name}</h2>
      <img src={img} />
      <p>{ingredients}</p>
      <p>{description}</p>
    </div>
  );
}
```

### 注意ポイント

#### ① 名前は一致させる必要がある

```jsx
const recipes = [
  {
    name: "カレーライス"
  }
];
```

```jsx
//OK
function Recipe({ name }) { ... }

//NG: titleは存在しないので undefinedになる
function Recipe({ title }) { ... }
```

#### ② 名前を変えたい場合

```js
const { name: recipeName } = person;
```

=> `name` を `recipeName` として使える 

---

### メリット

* コードが短くなる
* 見やすくなる
* よく使われる書き方

---

## どっちを使うべき？

どちらでもOKです

```jsx
function Recipe(props) { ... }
```

```jsx
function Recipe({ name }) { ... }
```

=> チームや好みによる

---

## まとめ

* propsはオブジェクト
* 分割代入で取り出せる
* `{ name }` のように書く
* よく使われるReactの書き方
