# Nested RoutesとOutlet

Nested Routesは

**ルートの中にルートを入れる**

という考え方です。

---

## 例

このアプリでは

```txt
/dashboard
/dashboard/notes
```

があります。

どちらも「先生用ダッシュボード」の中に表示されます。

---

## 親ルート

```jsx
{
  path: "dashboard",
  element: <Dashboard />,
  children: [
    {
      index: true,
      element: <DashboardHome />
    },
    {
      path: "notes",
      element: <DashboardNotes />
    }
  ]
}
```

`dashboard`が親ルートです。

`children`の中に子ルートを書きます。

---

## Outlet

親コンポーネントの中に

```jsx
<Outlet />
```

を書くと、そこに子ルートが表示されます。

### イメージ

```jsx
function Dashboard() {
  return (
    <section>
      <h2>先生用ダッシュボード</h2>
      <Outlet />
    </section>
  );
}
```

=> `/dashboard`なら`DashboardHome`

=> `/dashboard/notes`なら`DashboardNotes`

---

## index route

```jsx
{
  index: true,
  element: <DashboardHome />
}
```

これは

**親URLぴったりのときに表示する画面**

です。

=> `/dashboard` のときに表示されます

---

## まとめ

- 親ルートは共通レイアウトを持つ
- 子ルートは`children`に書く
- 子ルートは`<Outlet />`の場所に表示される
- `index: true`は初期表示
