# React JSX 導入

## ① 「あれ？これ普通のHTMLと何が違うの？」

今のコードって、ただ `<h1>` をJavaScriptに書いただけで、
「普通にHTMLを書くのと何が違うの？」と思いませんか？

---

## ② JavaScriptでUIを書くとどうなるか（JSXなし）

Reactを使わず、JavaScriptだけでUIを作る場合です。

```js
const h1 = document.createElement("h1")
h1.textContent = "Hello JS"
document.getElementById("root").appendChild(h1)
```

### 結果

* やることが多い
* 直感的じゃない
* 読みにくい

---

### ネストが増えるとさらに大変

```js
const div = document.createElement("div")
const h1 = document.createElement("h1")
h1.textContent = "Hello"
div.appendChild(h1)
```

=> HTMLなら一瞬で書けるのに、かなり面倒になる

---

## ③ React（JSXなし版）

Reactも内部的にはこういう形でUIを作っています。

```js
import { createRoot } from "react-dom/client"
import { createElement } from "react"

createRoot(document.getElementById("root")).render(
  createElement("h1", null, "Hello React")
)
```

=> Reactも実は「JavaScriptでUIを作っている」

---

## ④ JSX登場

```jsx
createRoot(document.getElementById("root")).render(
  <h1>Hello React</h1>
)
```

=> これを見やすく書けるようにしたのが JSX

---

## ⑤ JSXの本質

* JSXは **HTMLっぽく書けるJavaScript**
* JSXは最終的に `createElement()` に変換される

---

## ⑥ Before / After

### JSXなし

```js
createElement("h1", null, "Hello")
```

### JSXあり

```jsx
<h1>Hello</h1>
```

=> 同じことを、圧倒的に読みやすく書ける

---

## まとめ

* JavaScriptだけでUIを書くと複雑になる
* Reactも内部ではJavaScriptでUIを構築している
* JSXを使うことでHTMLのように直感的に書ける
