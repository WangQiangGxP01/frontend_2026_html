「静的なページならもう作れる」と思うかもしれません。しかし、このセクションの目的は単にページを作ることではなく、**React的な考え方に慣れること**です。

* スタイリング

実践的なチャレンジを通して理解していきます。それでは始めましょう。

---

## 従来のHTML

```html
<!-- index.html -->
<html>
  <head>
    <link rel="stylesheet" href="/index.css">
  </head>
  <body>
    <h1>Hello, world!</h1>
    <script src="/index.jsx" type="module"></script>
  </body>
</html>
```

## React版

```html
<!-- index.html -->
<html>
  <head>
    <link rel="stylesheet" href="/index.css">
  </head>
  <body>
    <div id="root"></div> <!-- ここが変更ポイント -->
    <script src="/index.jsx" type="module"></script>
  </body>
</html>
```

```jsx
// index.js
import { createRoot } from "react-dom/client"

createRoot(document.getElementById("root")).render(
  <h1>Hello React</h1>
)
```

---

## Reactの考え方

Reactでは、HTMLに直接 `<h1>Hello World</h1>` のように書くのではなく、**JavaScriptを使ってUIを作ります。**

これから少し上記の変更を説明します。

---

### ① 表示する場所を用意する

まずHTML側に、Reactが描画する場所を用意します。

```html
<div id="root"></div>
```

=> これがアプリの表示エリアになります。

---

### ② JavaScriptでUIを描画する

```js
import { createRoot } from "react-dom/client"
```

```js
document.getElementById("root")
```

=> HTMLの要素を取得

---

### ③ rootを作る

```js
createRoot(document.getElementById("root"))
```

=> Reactの「描画の土台」を作る

---

### ④ UIを表示する

```jsx
root.render(<h1>Hello React</h1>)
```

=> 画面にUIが表示される

---

## JSXとは？

```jsx
<h1>Hello React</h1>
```

=> JavaScriptの中にHTMLのように書ける記法
=> これを **JSX** と呼びます

---

## まとめ

Reactの基本の流れ：

1. 表示場所（root）を用意する
2. createRootで土台を作る
3. renderでUIを表示する
