# Reactコンポーネントの基本 ②

---

##  Reactの特徴：宣言的（Declarative）

Reactは「宣言的」にUIを書くことができます。

=> **「何をしたいか」だけを書く**
=> **「どうやるか」はReactが処理する**

---

## 命令的（Imperative）との違い

### 命令的（Vanilla JS）

```js
const h1 = document.createElement("h1");
h1.textContent = "Hello World";
h1.className = "header";

const root = document.getElementById("root");
root.appendChild(h1);
```

=> 手順をすべて自分で書く必要がある

---

### 宣言的（React）

```jsx
root.render(<h1 className="header">Hello World</h1>);
```

=> 結果だけを書く

---

## イメージ（レストラン例）

### 命令的

「50歩進んで右に曲がって…席に案内してください」

=> 手順をすべて説明

### 宣言的

「4人席をお願いします」

=> あとは任せる

---

## まとめ：なぜReactは良いのか

* コンポーネント = 再利用できるUI部品
* Reactは宣言的（Declarative）
* DOM操作を自動でやってくれる
* コードがシンプルになる
* UIの更新を自動で管理してくれる
