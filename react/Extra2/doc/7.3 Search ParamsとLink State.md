# Search ParamsとLink State

Search ParamsはURLの`?`より後ろの部分です。

```txt
/products?category=basic
```

この場合

```txt
category = basic
```

という情報をURLに持っています。

---

## なぜ使う？

例えば教材一覧でカテゴリを選んだとき

```txt
/products?category=data
```

のようにURLに残しておくと便利です。

### メリット

- URLを共有できる
- 更新してもフィルターが残る
- 戻るボタンとの相性が良い

---

## useSearchParams

React Routerでは

```jsx
const [searchParams, setSearchParams] = useSearchParams();
```

を使います。

値を読む:

```jsx
const category = searchParams.get("category") || "";
```

値を変える:

```jsx
setSearchParams({ category: "basic" });
```

---

## Linkで検索条件をつける

```jsx
<Link to="/products?category=basic">基礎教材</Link>
```

=> クリックすると`/products?category=basic`へ移動します。

---

## Link State

詳細ページへ移動するとき、一時的な情報を渡すこともできます。

```jsx
<Link
  to={`/products/${product.id}`}
  state={{ fromFilter: category }}
>
  {product.name}
</Link>
```

詳細ページでは

```jsx
const location = useLocation();
const fromFilter = location.state?.fromFilter;
```

で受け取ります。

=> 「どのフィルターから来たか」を覚えられる

---

## まとめ

- Search ParamsはURLに状態を残す方法
- `useSearchParams()`で読む・変える
- `Link to`に検索条件を書ける
- `state`で一時的な移動情報を渡せる
